# Propriedade intelectual

Este repositório não concede automaticamente licença de uso, reprodução, distribuição ou exploração comercial.

Antes de venda, investimento ou parceria:

- documente a autoria e contribuições;
- confira licenças das dependências;
- formalize cessões de colaboradores;
- registre marca e domínio quando adequado;
- delimite código próprio e componentes de terceiros;
- mantenha a versão comercial em repositório privado;
- defina no contrato se haverá cessão integral ou licença.

Este documento é organizacional e não substitui revisão jurídica.
