# Homologação física — encerramento da Fase 20

A automação cobre viewport, acessibilidade, teclado sintético, PWA e modo offline.
Os itens abaixo exigem aparelhos físicos e devem ser registrados antes da
homologação operacional definitiva.

## iPhone com notch — Safari

- [ ] retrato sem conteúdo sob a área do notch;
- [ ] paisagem com safe areas laterais corretas;
- [ ] teclado não cobre o campo ativo;
- [ ] modal permanece utilizável com o teclado aberto;
- [ ] rolagem não fica presa;
- [ ] navegação inferior respeita a área segura.

## iPhone com notch — PWA instalada

- [ ] abertura em modo standalone;
- [ ] splash e ícones corretos;
- [ ] navegação offline abre o aplicativo;
- [ ] atualização apresenta o aviso de nova versão;
- [ ] “Atualizar agora” ativa a versão e recarrega uma única vez;
- [ ] dados não aparecem em cache quando a sessão não os possui.

## Android — Chrome

- [ ] instalação oferecida ou disponível pelo menu;
- [ ] teclado não cobre campos e botões;
- [ ] retrato e paisagem sem overflow horizontal;
- [ ] retorno do histórico mantém a rota correta;
- [ ] navegação offline abre o aplicativo.

## Android — PWA instalada

- [ ] abertura em modo standalone;
- [ ] atualização controlada;
- [ ] caches antigos removidos;
- [ ] ícone, tema e splash corretos;
- [ ] reabertura após encerramento do processo.
