# Checklist de release

## Código
- [ ] `npm run validate:all`;
- [ ] `npm run format:check`;
- [ ] CI aprovada;
- [ ] dependências revisadas;
- [ ] changelog atualizado.

## Firebase
- [ ] projeto correto selecionado;
- [ ] regras revisadas;
- [ ] índices implantados;
- [ ] funções implantadas;
- [ ] segredos configurados;
- [ ] App Check testado;
- [ ] agendamentos verificados.

## Produto
- [ ] login;
- [ ] lançamentos;
- [ ] cartões e faturas;
- [ ] Money;
- [ ] Telegram;
- [ ] exportação;
- [ ] solicitação e cancelamento de exclusão;
- [ ] painel Admin.

## Comercial
- [ ] identidade jurídica preenchida;
- [ ] Termos e Política revisados;
- [ ] preço e escopo aprovados;
- [ ] SLA definido;
- [ ] suporte e contato publicados;
- [ ] backup e recuperação testados.
